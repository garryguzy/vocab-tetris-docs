## GitHub Pages

This repository is published via **GitHub Pages** from the `main` branch root.

If Pages is not yet enabled:

1. Open repository **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / **/ (root)**
4. Save and wait 1–3 minutes for the site to build
